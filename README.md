
# Machine Learning Internship Projects

A collection of machine learning projects completed as part of a
four-week, hands-on project internship.

## Project 1: Iris Classification

**Status:** Completed

### Objective
Classify Iris flower species using supervised machine learning.

### Models
- Logistic Regression
- Decision Tree Classifier

### Methods
- Exploratory data analysis
- 80/20 train-test split
- Feature scaling
- Classification report and confusion matrix
- Model comparison and visualization

### Tools
Python, Pandas, Scikit-learn, Matplotlib, Seaborn

## Project 2: California Housing Price Prediction

**Status:** In progress / completed after validation

### Objective
Predict median house values using the California Housing dataset.

### Models
- Ordinary Least Squares (OLS)
- Ridge Regression (L2 regularization)
- Lasso Regression (L1 regularization)

### Methods
- Missing-value imputation
- Correlation heatmap
- Feature engineering and interaction features
- Numerical feature scaling
- Categorical feature encoding
- GridSearchCV hyperparameter tuning
- RMSE, MAE and R² evaluation
- Actual-versus-predicted plots
- Residual distribution and residual-versus-predicted plots

### Tools
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
