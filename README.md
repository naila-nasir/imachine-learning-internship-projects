
# Iris Classification Benchmark

## Project Overview
This project compares two supervised machine learning models
to classify Iris flower species.

## Dataset
The Iris dataset contains four measurements:
- Sepal length
- Sepal width
- Petal length
- Petal width

Target classes: Setosa, Versicolor, and Virginica.

## Models
- Logistic Regression
- Decision Tree Classifier

## Methodology
- Exploratory data analysis
- 80/20 train-test split
- Feature scaling using StandardScaler
- Model training and evaluation
- Confusion matrices and decision-boundary visualizations

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score

## Tools
Python, Pandas, Matplotlib, Seaborn, and Scikit-learn.

## How to Run
Open the Jupyter notebook in Google Colab and run all cells.
